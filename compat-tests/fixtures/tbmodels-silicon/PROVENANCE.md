The accompanying `LICENSE.txt` is the unmodified TBmodels Apache License 2.0
file at the same commit. The fixture contains eight Wannier orbitals and 93
real-space shells. TBmodels itself uses these files to compare its Wannier90
import with PythTB.

The regression energies in `compat-tests/test_pythtb_api.py` were calculated
independently by assembling

`H(k) = sum_R H(R) exp(2 pi i k.R) / degeneracy(R)`

directly from the raw table and diagonalizing the Hermitian matrix. They are
fixed reference values rather than values generated by the Thouless parser or
compatibility model under test.
