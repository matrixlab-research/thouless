# Rust API

Rust is the implementation and composition layer for all scientific
capabilities in Thouless. Public items are documented with rustdoc and the
documentation build rejects missing public documentation.

Open the
[generated Rust API reference](https://matrixlab-research.github.io/thouless/rust/thouless/).

The source of truth for cross-language workflow mappings is
[`spec/api/thouless-native-languages.toml`](https://github.com/matrixlab-research/thouless/blob/main/spec/api/thouless-native-languages.toml).
